# 041 统一变更闭环与浏览器验收

日期：2026-10-21。代码基线 `16c875a`，本次为未发布开发；包与发布 Tag 保持 v0.2.3。功能状态以 [功能台账](../FEATURE_LIST.md) 为准。

## 范围与实现

- 旧基础本体、执行映射、映射修订、关系纠正及程序候选在提出时登记统一变更；复验与采用经共同服务。采用、变更回执与工作版在同一事务内提交，拒绝后不能从旧采用入口绕过。
- 程序新增对象、关系、合并与退役各有记录。部分采用只编译所选项，未选项保留为能继续处理的候选。拒绝记住端点、列与方式；重新提出依赖服务端计算的匹配率或目标唯一性变化，不能靠请求填写指标绕过。
- 复验失败保留失败原因；采用前重读当前基线、来源许可、快照与实际读取事实。过期返回冲突，需要重新读取或复验。旧取消入口同步撤回统一记录，同一候选的新内容不会被旧拒绝永久锁住。
- 命名、说明和直接关系可以真正采用。人工采用的关系保留稳定身份及可执行绑定，后续同结构重建与改名仍可查询。兼容换绑复制既有局部纠正，保留旧发布；涉及纠正的事实或绑定范围变化时拒绝静默迁移。
- 历史工作版可查看并提出恢复；复验检查固定快照、现行来源许可和绑定，采用后产生新工作版，历史记录不变。有待采用变更只提示其不包含在本次发布，不阻止发布已采用状态。

## 验证方法

测试沿管理 HTTP、既有领域服务、工作版、发布及消费查询边界执行。新增定向回归先观察失败，再实现修复；独立进行 Standards 与 Spec 两轴评审，发现项修复后复核。没有调用真实模型，没有更改用户企业工作区。

首轮集成检查：350 项测试中 349 通过，1 项因统一入口提前拒绝过期基线而需更新旧错误文案断言；快照整链通过。收尾 `npm run check`：361 项全部通过、0 跳过，类型检查通过；`npm run verify:snapshots` 通过。最后补充的 Agent 文字修订保留治理关系回归，与恢复 / 迁移 / 旧结构替换的 20 项定向集通过；完整检查再次通过。前端修改文件的 `node --check` 与 `git diff --check` 通过。

## 浏览器已执行场景

使用隔离临时目录、虚构客户 / 订单 / 产品 CSV、本地 HTTP 服务与真实 Chromium；不使用用户凭据。

- 桌面工作版入口、历史详情、变更列表及具体对象范围可读。
- 390px 宽屏幕可查看具体变更、复验及采用；技术版本默认收起。
- 采用请求服务端提交后人为丢弃响应，界面显示请求失败；重试沿用原 operationId，返回同一采用回执，只增加一个工作版。
- 拒绝要求具体理由，拒绝后详情显示已拒绝及原理由。
- 恢复历史工作版先形成提议；复验并采用后产生新的工作版，顶栏和历史列表同时更新。
- 服务重启后，工作版编号、采用记录及拒绝理由保留。数据 / 本体 / 发布三页、实际对象面板在 390px 可读；修正构建摘要挤压本体标题的问题。开发者开关可显示技术信息，关闭后收起。

浏览器证据位于本地 `output/playwright/041-*.png`，不将生成图、临时数据或访问凭据提交到 Git。
