# FEATURE_047 会话、上下文与执行分池验收（2026-10-19）

范围为 v0.3.0 未发布的 T047-01—04。未改包版本、Tag、远程或真实工作空间；本记录不维护功能状态。

## 领域与 HTTP 回归

- 新增会话长期保存、改名、归档、恢复与倒序游标分页。51 条历史消息重启后完整保留，跨会话游标拒绝；当前会话与页面由每个标签页显式传入，页面导航不写入服务端页面状态。
- 旧页面对话作为同一历史会话的只读任务分组，新增主任务承接后续消息；原消息、原任务、未决事项、采用记录、旧凭据与历史版本不重写。旧的企业/来源历史读取仍可按需使用。
- 用户交互按会话互斥；第二次发送提示等待或停止。多个会话与单个后台运行可以并发，后台文档、自动重绑、外部委托共用队列。上传新资料不会中止交互，停止一个会话不会停止其他会话或后台。
- 实际 KodaXDriver 的交互会话和后台使用独立 runtime/停止句柄；应用会话与 SDK 临时会话分离，每轮仅加载宿主已组装的上下文。保存、采用仍使用领域版本检查，两个会话基于同一成果版本提交时，后提交者收到版本冲突。
- 模型上下文由工作摘要、持久会话摘要、最近最多 12 条/12000 字、冻结引用组成；不自动注入完整企业档案、来源策略、检查列表。早期文本以有界摘录摘要表示；超过预算时先缩摘要，再缩近期窗口，原文仍完整保存。文档后台也使用同一初始上下文预算。
- 预算使用当前已安装 KodaX 的 `countTokens` 多语种估算，初始系统文本+宿主输入最多 8000 token（工具定义不计入）。这是估算上限，不是供应商逐请求精确 tokenizer 或后续工具返回量的保证；后续工具大结果问题仍由证据读取相关 Feature 处理。
- `sessions.test.ts` 公共 MemoryStore/应用/HTTP 边界 5 项通过；已有画布、自动文档、初始化、演示与来源摘要回归同步到跨页同会话合同。包含真实 SQLite 重启、并发版本冲突、两个交互会话和后台文档排队，未把模拟 driver 当成真实模型。
