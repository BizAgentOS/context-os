# 042 关系发现与身份对应验收

日期：2026-10-21。起点为 041 完成提交 `12b7ea4`，本轮未发布，包与 Tag 保持 v0.2.3。功能状态只在[功能台账](../FEATURE_LIST.md)，实现票在[042 设计块](../features/v0.3.0.md#feature-042)。

## 实现范围

- 首次构建保留独立实体，唯一外键、普通责任字段和自引用都形成可处理的关系提议。采用前没有执行关系；采用后通过共同查询服务读取。同结构重建保留已经明确采用的关系与身份规则。
- 关系复验检查快照中的真实类型、非空覆盖、目标唯一、基数、匹配率及声明的无环层级；限制最大展开深度。数值族先按数值语义定位目标，再检测层级循环，避免整数与小数文本差异漏环。准备与提交前重查快照及来源版本。
- `same_as` 将明确采用的左侧来源补充到右侧主对象，保留原来源对象和关系；`belongs_to` 保留两侧对象，产生可查询的归属关系。账号与人员不能因邮箱一致而合并。复验展示正反向歧义、匹配率、疑似机器人与读取覆盖。
- `identity_decision` 保存 `match / no_match`、规则、左右记录、依据、理由、决定人和时间。明确决定优先于字段规则；空右侧的 `no_match` 排除起点记录的全部规则匹配。事实或规则变化要求重新核对，不把旧决定静默迁到新事实。
- 工作版、发布差异、HTTP/MCP 消费与历史恢复固定决定的 `id@version`。旧发布没有身份决定字段时使用空集。兼容换绑复制决定；旧格式补充绑定通过同一兼容投影迁移。
- 两跳冗余边仍保留；只有已采用路径全量同目标才可明确弃用。95% 一致不能删除剩余直边。路径含局部纠正、身份治理、范围筛选或中间表时，原始 SQL 不能证明实际查询等价，弃用复验明确失败。
- 大事件表先保留普通实体与查询，活动分类另行提议、确认。变更详情显示来源文件、字段、记录决定与替代路径；连续复验 / 采用期间的按钮状态及窄屏表格已校正。

## 边界

身份规则复验最多读取 10000 条，查询规则解析最多读取 2000 条；未完整读取会明确报告待核对或无法确认，不冒充全量。明确记录决定按记录键读取。无 Snapshots 的旧构造回退仍不提供全量快照保障，生产 App 注入 Snapshots。范围治理的替代路径目前安全拒绝弃用，后续如需支持，应按共同查询服务证明等价。没有发布、调用真实模型或迁移用户实际工作区。
