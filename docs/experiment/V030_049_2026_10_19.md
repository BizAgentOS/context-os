# FEATURE_049 事件推送与前端模块化验收（2026-10-19）

范围为 v0.3.0 未发布的 T049-01—03，并集成 FEATURE_047 的会话入口。包版本、Tag、远程与实际工作空间均未改动。本记录不维护功能状态。

## 事件与页面更新

- 管理身份保护的 `GET /api/events` 推送来源、版本、任务、消息、步骤和会话引用；流式文字携带所属会话。普通事件只携带引用与版本，不发送源数据行、凭据或整份工作台。
- `GET /api/snapshot` 用于初次/重连校正，`scope=agent|data|ontology|release|shell` 限定返回字段；数据范围不重发聊天消息。事务提交后发布变化，回滚不发布；视图订阅错误不能回滚已提交领域写入。
- 每个进程最多保留 512 条事件；浏览器用 Last-Event-ID 自动补发。过期游标或进程重启返回 reset，客户端重新读取快照。20 秒 SSE 注释保活不查询工作空间；慢客户端超过 256 KiB 待发送量时断开，随后校正。
- 移除 1.2 秒全量轮询、画布 JSON 指纹和数据/构建对话框的循环轮询。来源、发布、图谱进度按事件更新各自模块；表单弹窗独立于页面更新，数据/发布 DOM 区域保留节点、展开和滚动。
- 拆出共享状态与事件订阅、Agent 对话、任务中心、待处理投影、企业资料、会话与离线接入展示模块；数据、本体、发布仍使用各自模块。`app.js` 从 3815 行降到约 2640 行。模块之间通过事件和明确回调通信；任务到本体定义不再模拟点击另一个模块按钮。
- 删除旧 `renderLegacySetup`、旧 `renderConsumption` 和旧消费详情写界面。企业资料作为数据页的管理面板保留；旧消费只读/撤销入口继续使用历史接入模块。离线/演示接入显示已保存记录，完整演示与分享改造仍属于 FEATURE_067。
