# 飞书已读资料与本体入口验收

日期：2026-09-17。属于 FEATURE_019 的 T019-05；在线 docx 的真实读取验收 T019-03 仍未完成。

## 实现

- 页面和内部 Agent 的飞书 SDK 共用 `FeishuDocuments`：明确读取后保存真实文本来源，保留原链接、远端对象身份、格式、快照读取时间和内容摘要。文本附件不伪造飞书版本。
- 按远端域名、对象种类、文档 ID 识别同一来源；同名上传文件独立。内容/标题/文档 revision 变化生成新本地版本，完全相同重读复用已有快照。列表日期为快照读取时间，不将重查时间冒充新内容。
- 企业页直接显示飞书已读份数和文档；详情可以看到正文、字符数、版本、原链接和本体引用的概念/关系。候选与采用明确区分，旧快照引用不标为最新资料已用于本体。账号断开后本地资料仍可查看。
- 本体化绑定来源 ID/版本并进入既有本体工作区。模型仍须加载 Skill、实际分段取证、保存候选；用户核对后才采用。已有引用可直接返回工作区查看。无模型时正文保留、生成入口阻断并给出提示。
- 运行有效性经宿主 SDK 上下文传至保存边界，停止后不得保存迟到结果；同一生成请求重试先检查消息回执，不会停止已接受的运行。

## 验证

1. `npm run check`：类型检查与 157 项 Node 测试通过。新增公共服务/HTTP 验证覆盖持久化与重启、相同内容重读、版本更新、同名上传隔离、目录来源种类、原文引用与定位、无模型、候选与采用、旧版引用、过期资料拒绝、取消与重复请求。
2. `npm run export:html` 通过；仓库没有独立 lint/build 脚本，构建沿既有离线导出入口。
3. 真实账号在浏览器读取用户指定《01-仓配门店与库存快照.md》成功，保存 622 字符。重新打开页面和资料弹窗，正文仍可查看，主环境显示“尚未用于本体”。实际业务正文和远端标识未写入本验收文档。
4. 隔离状态目录 + 确定性测试 driver，经实际浏览器点击“用于本体化”生成含 2 个概念、1 条关系和真实快照片段的候选；资料详情显示候选引用，返回工作区并人工采用后显示已采用 v2。该测试验证产品链路，不代表真实模型理解质量或主企业已采用。
5. 桌面与 390px 资料弹窗检查通过，无页面横向溢出或浏览器控制台错误。临时窗口和尺寸覆盖已清理。
6. Standards / Spec 独立评审完成，两处运行生命周期问题修复并以失败→通过回归确认，已有候选返回入口已补齐，无遗留发现。

## 当前限制

主环境未配置模型，指定文件没有生成或采用本体。资料内容属于星桥仓配，当前企业为海致科技，使用资料生成时仍须保留并核对企业归属，不可静默合并。不会导入整个目录或自动同步，不会把文本快照直接当作业务实例映射；MCP 对外发布继续使用独立的已采用本体流程。
