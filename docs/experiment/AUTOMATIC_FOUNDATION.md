# 文档自动构建本体验收

2026-09-17，按用户要求：接入文档后自动构建第二页基础本体，无需确认或点击采用。

- 页面上传 Markdown/TXT/CSV、飞书正文保存后，按来源 ID 与版本记录持久化待办。同一版本不重复构建；无模型时等待连接，重启恢复排队，连接成功后自动继续。
- 使用现有 KodaX 驱动及单一执行槽，加载企业基础本体 Skill，仅开放基础定义读取、文档分段读取和生成工具。按批次读取真实片段，校验本轮每份资料的依据和当前版本后自动生效。
- 第二页显示排队、构建、完成数量或失败原因。切换页面不取消自动构建；连续上传排队处理。失败可重试，停止/删除后的迟到结果不能自动生效。
- 未知保留；含义冲突保留原有效定义及新提议、双方依据，不伪造解决。删除资料不移除历史本体依据，历史引用仍可查；它不会阻断后来新资料的构建。
- 此流程生成基础概念、关系和依据；业务执行映射、对外授权与 MCP 发布仍沿用原入口。旧任务上传 API 的对话流程保持兼容。

## 验证

公共应用边界覆盖自动采用无 pending、Markdown/CSV/飞书全部覆盖、无模型与重启恢复、导航及连续上传、失败重试、删除过程中迟到结果拒绝、删除旧资料后继续构建、模型保存与测试先于自动构建、冲突保留旧定义与历史证据。

隔离浏览器实测使用确定性测试驱动：上传一份仓配 Markdown 后直接切换第二页，出现「本体已自动构建并生效 · 1/1 份资料」，显示门店、仓库两个概念与一条补货关系，版本为已采用，全程无确认按钮。该实测验证交互与服务链路，不代表真实模型的抽取质量验收。
