## 交付

共同领域服务 EvidenceService 通过 evidence_collect/list/read 与管理 HTTP 提供采集、分页发现和历史读取。围绕明确对象/关系查询保存文档片段、指标观测与融合对象依据；三类来源保持各自读取时间、身份和覆盖，不混成单一“真实值”。记录是有界历史证据，文档关联理由和维度对应仍需业务核对；不修改本体，不扩外部授权，不自动计算或生成业务结论。

取证每次最多10对象/20字段、1–3文档与1–3指标，每轮4次；超过256KB拒绝保存。指标只能按显式维度精确匹配返回对象，空绑定仅为背景；未知属性保留不确定，不把聚合数值当个体属性，不保证对象期间与指标期间一致。局部读失败保留其他已读部分，撤销/版本变化/停止使整次不能保存。
