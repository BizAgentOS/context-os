# 本体图查看与验收

2026-09-08，T005-06。用户希望参考 Semantica，让本体页更直观。本轮复用原有四页、对象服务、固定版本与证据接口，实现原生 SVG 连线及可点击节点，没有增加图数据库或前端框架。

## 如何查看

运行 `npm run demo`，打开终端给出的本机管理链接（默认 8794），进入“本体”。

1. **定义：**显示澄川热力的 6 类对象、10 种关系。点“投诉”查看业务含义、属性和映射资料；点“居民回访”关系可查看投诉编号的连接方式与两端来源。概念草稿可从定义版本下拉框切换。
2. **对象：**选择“投诉 / TS002”。图中同时出现松园小区 1 号楼（B04）、工单 GD002、回访 HF002。点邻居查看其字段；点“以此对象展开”继续查看直接关联。
3. **来源：**HF002 的“客服回访.csv · 第 2 条”打开准确版本和高亮原始行。返回保留选中的回访。资料记录和对象依据没有改为前端推断。
4. **验证：**沿用已有业务问题、执行结果和业务确认。“图上有关联”本身不构成供热恢复结论。

缩放、适应和图内滚动只影响图。窄屏时检查栏排在图下方，可滚动查看；输入框继续作为前景浮层。选择节点不会重置当前图的缩放和键盘焦点。

## 边界

- 定义图与对象图分别显示类型和实例。草稿没有映射记录时，明确显示尚无对象。
- 对象图按所选本体保存的来源版本读取，仅展开已经定义的直接出向关系；点击邻居可继续展开。不会自动补充反向关系或生成新的业务事实。
- 每次最多显示 20 个对象；超过时提示并提供被截断关系的完整关联列表。对象选择每组 30 条，可翻页。
- 暂无关联记录时解释缺口。读取失败展示重试，不把失败当作零对象。切换对象、子页、模型或页面后，迟到请求不能覆盖新视图。
- 不改变本体采用、对象方法、来源限制、消费权限和演示问答方式。

## 实测

- `npm run check`：类型检查与 52 项 Agent 测试通过；新增浏览模块通过 JS 语法检查。
- 1280×900 桌面：6 节点/10 关系；选中定义和关系，查看字段连接说明与依据；缩放后选中节点保持缩放。
- TS002 图展示 4 个实际对象、3 条直接关系；HF002 显示“未改善”和原始反馈。打开回访第 2 行并返回后仍选中 HF002，画布没有跳动；以回访继续展开得到 HF002→TS002。
- TS003 显示缺少“居民回访”，没有推断其已恢复。概念草稿显示 3 个概念、2 条关系，在对象视角解释尚未映射；既有 4 份本地验证仍可查看。
- 390×844 窄屏：页面、画布和视口宽度均为 390px；图自身缩放正常，点击节点后的详情及来源可滚动访问。
- 注入一次对象读取 500 错误：页面显示读取失败，移除注入后“重试”恢复 4 个对象。将来源请求延迟并切到“定义”，迟到的来源响应没有打开旧详情。注入仅在测试浏览器内，不修改演示资料。
- 双轴复核修正了图重建导致缩放丢失、来源返回丢失选择、截断列表类型错误、迟到详情覆盖和重复自环标签重叠。自环独立几何检查涵盖 1/2/6 节点、4 条自关联，路径不同且曲线与标签在画布内。
