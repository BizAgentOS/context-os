# 全局映射修订与治理影响验收

日期：2026-09-14；T015-04；实现前基线 `81f2e43`。本地提交见 Git 历史。FEATURE_015 四票完成，下一项 T016-01「融合对象的许可消费视图」；未发布。

## 交付及范围

表单与内部 Agent 通过 MappingChanges 操作同一修订。首轮每次修改一个已有主/附来源属性的字段绑定，或一条关系的起点/目标字段规则。保存候选、样本前后依据和结构化差异；检查重读来源，管理员确认具体检查版本后原子保存新执行映射与采用回执。候选不生成可绕过治理流程采用的独立 live 候选。新映射保留 base 和 changeRef，旧映射与既有授权不覆盖。

影响报告用同一 changeRef 关联内容和样本，最多5起点/每关系20目标，保留实际覆盖、逐属性冲突/匹配依据。修改附来源匹配键时比较其补充属性；相关关系定义列出但不暗示逐实例验证。已保存局部纠正按类型/关系汇总并可作为提议依据；不是全企业异常扫描。第三页真实消费影响和迁移仍待 T016-03。

## 自动验证

沿既有管理 HTTP、Agent 领域工具、独立 HTTP/MCP 源和外部 HTTP 消费者进行测试。最初公共测试在不存在 changes 接口时失败，实现后通过。新增2项端到端测试覆盖：

- 主/附来源字段与关系规则差异、样本前后值、治理分组、同一变更引用及历史版本读取。
- 不检查不能采用、同键异参拒绝、重复采用返回原回执、两个检查候选同时采用仅一份成功、采用后取消不能冒充回滚。
- 上游值/冲突依据变化拒绝旧候选，业务 readAt 字段仍参与差异和漂移校验；相同对象集合只是源返回顺序不同可继续检查。
- 主业务键改绑导致附来源反馈/上门次数变为缺失，影响报告如实包含这些字段。UTF-8 大字段导致证据超256KB时不保存新候选。
- 实际 Agent 工具可保存、读取修订但没有采用工具；第一来源请求在途时停止不保存，受测 HTTP 来源不追加请求。独立评审另用两个非融合类型确认停止后不读第二类。
- 新映射查询返回新值；原映射与已经启用的 v2 独立 HTTP 消费者仍返回旧口径值。

类型检查、115项 Node 测试和22项 Python 测试通过；HTML 导出与 JavaScript 语法检查通过。没有独立 lint 脚本。

## 复核与限制

最终 Standards 与 Spec 均为0遗留发现。独立 Standards/Spec 反例促成匹配键联动、业务时间字段、停止后追加I/O、样本顺序、迟到问题复选框恢复与草稿拥有者等修复。实际组件验证：慢请求期间冻结；关闭在途表单A、重开编辑B后，A的晚到成功不删除B草稿；问题加载晚于保存发起、保存失败后仍可编辑复选框。未决操作ID随会话草稿保留；刷新页面不恢复草稿。

单企业本地管理员，没有多用户审批或源回写。前后读取非跨源原子，报告不证明业务真实；来源不稳定时需重新调查。首批样本非统计估计，关系依赖未全部展开，全量消费者影响未评估，局部纠正不自动迁移。新旧映射分别保留，明确显示新ID/版本，不将内部采用说成对外发布。
