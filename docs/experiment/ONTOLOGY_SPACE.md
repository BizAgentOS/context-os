# 动态三维本体空间验收

2026-09-17 · FEATURE_022 · 本地实验，未发布。

## 使用路径

打开 `http://127.0.0.1:8788/`，进入“本体工作区”。点击概念进入局部聚焦，再点击概念或关系查看具体定义。详情中的分组展开关联、关系定义、依据与来源映射；点击空白、关闭或 Escape 逐级返回。顶部支持查找、旋转后的复位、缩放和暂停；管理、实际对象与共同取证保留在“工作区”入口。

输入框是同一个原有聊天组件：全局右下、局部下方居中、详情右下。浏览图不改变固定的讨论对象，点击“引用到对话”才绑定当前定义及版本。旋转、动画和发光不是实时业务事件，连线粗细区分定义关系与辅助依据，不代表尚不存在的关联强度字段。

## 数据与实现范围

使用用户现有的海致科技候选 v1：5 个概念、2 条关系、2 份网页依据、0 个已映射概念。依据节点对应实际 evidenceRefs；没有给孤立概念补造关系，没有移植参考视频中的经营指标或统计。未知与冲突保留在具体定义中。

Three.js 0.186.0 从本地 npm 依赖打包为浏览器模块，无运行时 CDN。球体、轨道、灯光、相机和连线实时绘制；节点标签由同一相机坐标投影。GUI 状态与领域状态分离，详情和显式引用仍调用已有共同工作上下文服务。普通静态路由及 `/agent/` 前缀都提供本地资源；离线热力演示继续使用原有演示数据和展示，不冒充在线企业。

## 实际验证

- 导航公共边界先红后绿：点击全局→局部→详情；无效选择拒绝；只有实际关系和依据连接；A→B→B-C 正确显示 B 端点并回到原聚焦 A。
- 147 项 Node 测试、`npm run typecheck`、`npm run export:html`、修改的 JS 语法与 `git diff --check` 通过。
- 首次全套检查发现旧工作上下文测试没有等待异步 adopt，导致偶发 200/400 竞态；补齐 await，未改变采用服务。
- 浏览器 1470×837：点击概念/关系与扇区、0 映射空状态、真实详情、引用、草稿、历史、键盘进入/返回、空白返回、旋转、缩放、复位及暂停；检查到的控制台错误为 0。
- 浏览器 390×844：无横向溢出，图谱适配较窄视场，详情可滚动；输入框与详情保留 16px 间隔，关闭和输入入口始终可见。输入宽度变化后重新计算实际高度，避免留下过渡中的临时换行高度。
- “定义与映射”旧详情的引用操作关闭外层模态并把焦点交回输入框；“实际对象”与“共同取证”均显示真实空态。企业与数据、消费与治理往返时无三维画布残留，恢复原主题。
- Standards / Spec 双轴评审已完成。资源释放、旧详情主题、父弹窗焦点、关系端点与映射目标、分组及导航键盘焦点问题均修复后复核通过。

当前企业没有执行映射、只有一个基础版本，已填充实际对象与多版本切换未在这个浏览器样本中验证；沿现有服务测试和组件入口保留。当前没有配置模型，本轮未发送真实模型请求，不宣称验证了 AI 推理结果。WebGL 失败与减少动画分支经源码评审，当前浏览器支持 WebGL，未强制制造 GPU 故障或修改系统动画偏好。大规模图谱性能不作为本轮验收结论。
