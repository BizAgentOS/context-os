## 真实 Agent 与浏览器

使用KodaX SDK 0.7.96-beta.2及已配置DeepSeek，在独立临时企业工作区运行真实模型，来源为独立HTTP/MCP热力业务夹具。用户要求客服回访Agent只读投诉编号、状态、实际反馈及回访关系；模型读取映射后保存草稿，未启用或获取密钥。真实视图回执为918bb0c2-c566-4364-8b17-e19c78a510da v1，固定映射ae0b5308-4357-4d99-bdb4-2ba7c25e0313 v2，两端许可正确。

人工浏览器启用上述草稿后，v3对象请求200并留下访问记录。另用界面创建只许可投诉$id和实际反馈的视图，以键盘Enter提交，首次密钥调用TS002得到“未改善”，读取未许可回访类型403；断言通过。无明文密钥进入记录或截图。1440×1000桌面与390×844窄屏检查通过，保持原有三页样式，视图范围和按钮可阅读。

真实模型末尾把按钮称为“启用访问”，实际按钮为“启用此消费视图”，措辞未完全一致，未影响保存及人工操作。样本来自本地夹具，不代表已对接真实生产企业。临时8897服务用于验收，原8899用户演示未改动。
