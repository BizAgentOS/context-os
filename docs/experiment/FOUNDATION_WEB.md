## 限制

读取仅支持可直接获取的 HTML/纯文本；不运行页面脚本、不登录、不解析 PDF，也不保证所有验证页面都能自动识别。512 KiB 是网络获取边界，局部覆盖不是全面调查。读取时快照不证明当前网站仍相同，不是完整网页归档或自动新鲜度服务。模型解释仍需核对，公开宣传不是经审计事实。

本票未改造原有全部通用工具的网络边界，仅对基础网页证据入口实施公网解析/固定连接检查；未新增消费接口、企业来源映射或第二个 Agent 循环。以上为开发验证，不是模型方法优越性的评测。
