## FEATURE_038：默认快照与统一读取回执

- 可变 HTTP 来源首次同步后修改源值，工作区 HTTP、Agent `live_query`、`context_read` 仍读取已采用快照；显式 `live` 读取新值。再次同步后工作版更新，旧发布 / v4 仍读取锁定快照，回执同时附本体、映射和发布版本。
- 部分快照 / 部分实时与补充来源读取失败均保持准确逐源状态；不能因失败只剩一个快照来源便声称全部快照。外部类型说明按获准字段筛来源，不泄露未授权补源；说明、HTTP 和真实 stdio MCP 来自同一读取合同。
- 新测试先红后绿，18 项相关回归、类型与 JS 检查通过；真实 KodaX 只读结果见 036 小节。浏览器实际对象的已采用快照显示 2026-10-18 的数据截至，显式实时显示本次读取时间；13 条人员记录可读，来源展开不显示原始回执 JSON。
- 兼容边界：尚未登记受管数据集的历史映射继续按需读取并明确 `live`；已登记快照策略却没有已采用版本时，默认读取拒绝并要求先同步或显式实时。快照时间并非统一业务时点，界面继续说明跨源时间可能不同。

## FEATURE_037：可理解界面与历史保留

- 删除画布和旧 task 的自由文本采用分支。“采用这版”等文字只作为消息；采用必须调用带明确候选 / 版本的管理决定边界。保留失败时的原候选与事务回执验证，旧聊天采用回归改为显式按钮决定。
- `trimMessages` 只返回模型窗口，数据库记录保留；当前页默认 40 条，游标分页读取更早消息，不接受其他任务游标。存储重启回归保留 65 条；HTTP 回归保留 61 条。浏览器隔离副本另加入 65 条明确标记的验收消息，加载后首条 / 末条各出现一次，后续状态轮询仍保留已加载旧消息；失败可重试。
- 来源以一份服务投影为准，上传 CSV 的内部连接去重，分类 / 可用状态 / 规模 / 对应实体统一。快照截至读取 activeVersion 对应快照的 syncedAt，新增结构待确认和无变化同步不把最近同步时间冒充生效数据时间；多数据集保留范围、以最旧已采用时间显示，共有实时 / 未同步数据时保留未知。
- 默认视图的引用、映射规则、纠正依据、共同取证、对象读取和版本差异改为业务详情，完整 JSON 只在开发者技术区。UUID 在普通标签中使用可区分别名，真实领域引用不变；开发者开关恢复技术内容。能力诊断入口只在开发者视图出现，普通用户仍可接入和查询。接入配置提供复制 / 下载，原始配置仅技术区可见。
- 三页英文页眉移除，CSV / 飞书与文档状态不再误归；可发布工作版的主按钮为“检查并发布”。普通“当前版本共 10 行”用中性色信息框（实际浏览器 rgb(38,69,104)，错误标记为空）；实时读取设置单列，避免与预览混排。
