| 版本管理 | 产品包、MCP 标识和设计台账为 0.2.0 系列；第三页发布的数据底座版本独立管理 |

## 限制与下一轮验证

- 当前存取策略是 HTTP/MCP 按需读取及 CSV 上传快照。没有接入 Helix DuckDB/Parquet 全量同步、图数据库或全部连接器。**（0.2.1 已解除：结构化来源默认同步为 DuckDB/Parquet 不可变快照；图数据库与其余连接器仍未接入。）**
- HTTP/MCP发现最多100条样本；CSV键检查使用完整已上传行。**（0.2.1 已解除：发现与检查在全量快照上运行，单次快照默认上限 100 万行，超限明确标注不完整。）**最多40个记录能力、20个执行类型、30个程序构建概念，超限明确报错，不静默截断。
- 重叠只产生待核对线索，不自动认定业务关系或合并实体。复杂语义和关系仍需人或 Agent 修订。**（0.2.1 已变更：按 Helix 规则在全量数据上自动形成跨来源合并与关联候选，仍需检查和采用；业务含义仍需人或 Agent 核对。）**
- 已有未采用基础修订时，自动更新只生成并检查候选，等待用户明确采用。更新源配置或上传文件版本可能使原映射不可读，需重新检查；不会假称所有历史事实仍可重放。
- 发布检查为每类有界样本读取，不是全量质量认证。定义版本不冻结源系统值；**（0.2.1 已解除：发布同时锁定各来源快照版本，接入方读取不随来源变化；设为实时读取的数据集除外并显式标注。）**当前为本地单企业、stdio MCP，没有远程MCP托管、多租户或完整记录级权限。
- 外部委托有24次读取及512 KiB工具结果预算。模型未配置时等待；重启中断任务不会自动重放；结果为模型解释，与来源读取分开展示。
- 下一轮选择投研或其他实际场景，接入获准来源与模型，验证语义修复质量、查询效果和真实token/时延成本。

## 0.2.1 更新（2026-10-15）

对应 [FEATURE_031—035](../features/v0.2.0.md#feature-031) 及后续修复，按 [ADR-004](../ADR/ADR-004-managed-snapshots-and-pinned-releases.md) 移植 Helix 快照底座。发布为本地提交与 Tag `v0.2.1`，未推送远程。

| 环节 | 0.2.1 实现 |
|---|---|
| 数据 | HTTP/MCP 与 CSV 结构化记录同步为不可变 Parquet 快照（进程隔离 DuckDB 执行器）；内容不变不新增版本；字段结构变化进入待确认并列出逐字段差异，确认前继续使用原版本且不能发布；数据集可改为实时读取 |
| 本体 | Helix 全量发现：身份键、跨来源合并、关联、两跳去冗余；重新构建保留已采用映射，新发现的合并追加为附来源，主来源未映射而成员已映射时并入该映射 |
| 检查与修订 | 候选在全量快照上检查身份唯一、字段、附来源与关系匹配率；人或 Agent 提出的映射在采用时、映射修订在检查时，自动比较前后的全量检查，引入新问题或检查无法完成时不通过 |
| 发布 | 发布锁定本体、映射与快照版本；发布与升级前显示行级数据差异；旧版本接入方继续读取锁定快照 |

可重复验证：

- `npm run check`：类型检查与 219 项测试。
- `npm run verify:snapshots`：不调用模型，经管理与消费 HTTP 接口走完 同步 → 构建（CRM 合并工商登记，订单→企业）→ 全量检查与采用 → 发布 v1 并接入 → 来源数据更新（v1 仍读旧值）→ 来源字段类型变化（待确认、发布被阻止、v1 不受影响）→ 确认并发布 v2（行级差异）→ 升级（旧密钥 403）→ 撤销。加 `-- --keep` 保留临时工作区。

浏览器验收：本机 Chrome 在隔离状态目录与虚构来源上走通上述链路及结构变化确认，1470×801 与 390×714 无横向溢出。截图与逐项说明在外层研究工作区 `output/product/ade-035-ui-2026-10-15/`。

### 当前限制

- 快照保存在本机状态目录下的 `data/`，未加密，保留最近 5 个版本及被发布引用的版本；没有远程存储、多租户或记录级权限。
- 文档与知识片段、指标观测仍按需读取；实时读取的数据集不参与全量发现，发布时标注为非锁定。
- 单次映射最多 20 个对象类型、30 条关系、每个对象 3 个附来源；超出部分报告为问题，不静默截断。经其他数据集间接匹配的合并只保留在候选中。
- 全量复验覆盖映射的采用与修订；基础概念文字修订不涉及数据检查。
- 尚未接入真实业务数据与真实模型做场景验证。

浏览器补验：在隔离状态目录与虚构 HTTP 来源（5 行来源、同步上限 3）中检查数据快照详情、本体候选检查和发布详情。数据页显示“字段画像（已保存范围）”及来源总量；本体显示“快照检查（仅可用范围）”和 3 / 5 行提醒；发布清单保存并显示“不完整：3 / 5 行”。没有调用真实模型，也未更改用户业务数据。
