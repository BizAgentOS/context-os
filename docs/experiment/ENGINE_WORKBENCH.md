## 限制与下一轮验证

- 当前存取策略是 HTTP/MCP 按需读取及 CSV 上传快照。没有接入 Helix DuckDB/Parquet 全量同步、图数据库或全部连接器。
- HTTP/MCP发现最多100条样本；CSV键检查使用完整已上传行。最多40个记录能力、20个执行类型、30个程序构建概念，超限明确报错，不静默截断。
- 重叠只产生待核对线索，不自动认定业务关系或合并实体。复杂语义和关系仍需人或 Agent 修订。
- 已有未采用基础修订时，自动更新只生成并检查候选，等待用户明确采用。更新源配置或上传文件版本可能使原映射不可读，需重新检查；不会假称所有历史事实仍可重放。
- 发布检查为每类有界样本读取，不是全量质量认证。定义版本不冻结源系统值；当前为本地单企业、stdio MCP，没有远程MCP托管、多租户或完整记录级权限。
- 外部委托有24次读取及512 KiB工具结果预算。模型未配置时等待；重启中断任务不会自动重放；结果为模型解释，与来源读取分开展示。
- 下一轮选择投研或其他实际场景，接入获准来源与模型，验证语义修复质量、查询效果和真实token/时延成本。
