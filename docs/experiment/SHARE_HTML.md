# 单文件 HTML 演示

用于给未安装 Context OS 的同事查看产品效果。展示企业、数据、本体、连接四个页面，沿用当前热力公司演示的黑白画布和图谱交互。

## 生成与发送

在项目目录执行 `npm run export:html`。默认生成 `output/share/Context-OS-热力公司-演示.html`；也可以执行 `npm run export:html -- /目标目录/演示.html` 指定路径。

把这一份 HTML 作为文件附件发给对方，对方下载后用桌面浏览器打开。无需 Node.js、Context OS 服务、模型 API Key 或联网。部分聊天软件的附件预览不运行 JavaScript，需保存文件后在浏览器打开。

## 可查看的内容

- 企业名牌、业务、范围和目标。
- 八份虚构资料的表格、正文、用途与字段说明。
- 本体定义关系图、对象关联、字段和原始记录依据，以及已有业务验证结果。
- 应用连接、读取范围和示例访问记录。
- 各页固定的示例问答，回答取自同一份虚构演示快照。

离线文件明确标为演示；上传、修改、授权、停用、发布和真实模型调用仍需运行中的产品。该文件不会接收后续服务端数据更新，也不会自动连接真实第三方 Agent。

## 实现与边界

`scripts/export-heating-html.ts` 创建临时隔离演示空间，采集只读快照后关闭清理；不读取当前用户空间。现有前端代码与样式通过构建内联，数据以 JSON 嵌入，离线适配器提供本地导航、查询和示例回答。脚本数据转义 `<`，HTML 的 CSP 禁止网络连接、外部资源和表单提交；文件不包含管理员凭据、消费密钥、个人目录或实际服务配置。

构建文件在 Git 中忽略，保留生成脚本、演示来源和验证记录，方便以后重新生成。
