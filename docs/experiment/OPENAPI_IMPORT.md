# Swagger / OpenAPI 来源导入

2026-09-16，FEATURE_020；本地开发能力，未发布。

## 使用流程

企业与数据 → HTTP API 接入 → **添加接入**。也可从“查看接入方式”的来源管理弹窗进入“导入 Swagger / OpenAPI”。

1. 提供 JSON/YAML 文档 URL、粘贴内容或上传文件（最多 2 MB）。URL 必须指向接口描述文档，不能填 Swagger UI 网页。受保护的文档先下载，再上传或粘贴。
2. 勾选需要的数据接口；展开“字段与读取规则”，核对唯一身份字段与采集字段。文档缺失分页参数时，填写每页条数参数和从 0 开始的偏移量参数。
3. 核对连接名称、Base URL 与认证。支持无认证、Bearer、请求头 API Key、Basic；选择的认证须符合接口声明。文档未声明认证时允许手动补充。
4. 点击“测试所选接口”，每个接口实际读取最多 3 条。样本显示字段、读取时间、来源报告总量或未知状态。失败和空样本不会创建来源；修改选择或配置后必须重测。
5. 测试通过后“确认导入”。已测试回执 30 分钟内有效，重复提交同一回执返回同一来源。HTTP API 列表与数量更新，保存的接口可通过原来源服务读取。成功页可将映射建议放入助手输入框，由用户继续本体工作流。

弹窗沿用黑白灰样式，标题、右上角关闭与底部按钮固定；长内容在内部滚动。支持 ×、Esc 和点击遮罩关闭；提交保存期间暂时禁止关闭，防止回执状态不明。

## 当前合同与限制

- Swagger 2.0、OpenAPI 3.0/3.1，JSON/YAML；本地 `$ref` 与兼容 `allOf`。外部引用不抓取，复杂、循环或超过预算的结构给出原因。
- 只导入 GET 列表。需要唯一的记录数组和 1–100 个标量字段，可从包装对象中识别数组及总数；身份为字符串或数字。字段必须实际出现在返回记录中，可取消选取不需要或缺失的字段。
- 当前使用 limit/offset；分页名缺失时可补配。页码、游标、必填业务/路径参数、GET 请求体、多个返回数组、写入接口暂不支持。文档仍显示这些接口及原因。
- OAuth、Cookie、查询参数密钥及多个凭据组合暂不接入。API Key 使用独立请求头。远端使用 HTTPS，本机开发服务允许 HTTP；地址不含内嵌凭据/查询/片段。重定向不跟随，响应限制 2 MB、单次读取超时 12 秒。
- 来源只保存连接、字段/分页契约及文档摘要元数据，样本和原始文档不进入领域记忆。凭据复用权限为 0600 的本机独立来源凭据文件。预览的凭据只存在短期进程状态，提交后清除临时副本；重启使所有未提交回执失效。
- 文档结构、样本测试与业务真实性分别处理：测试成功不代表自动同步、完整分页验证或本体已经采用。接口数据按需读取，仍使用原来源版本与撤销检查。

## 验证

公共边界：`node --test tests/agent/openapi-import.test.ts tests/agent/live-sources.test.ts`。使用独立本地 HTTP 服务，不调用第三方业务账号。

覆盖文档 URL 与 JSON/YAML、Swagger2/OAS3、内部引用与宽/深引用预算、长路径/自动命名、Base URL 路径保留、只保存勾选 GET、API Key/Bearer/Basic/无认证、凭据脱敏与独立存储、身份/字段/分页校验、空样本拒绝、篡改候选拒绝、重定向不携带凭据到另一服务、大小限制、过期回执、重复提交和重启后的读取。

浏览器在独立临时工作区验证：URL 解析 → GET 勾选（DELETE 禁用）→ 两条真实夹具样本 → 修改名称后必须重测 → 确认导入 → 刷新后 HTTP API 数量与来源保留。文件上传入口读取本地 JSON 并解析；不在用户企业中保存测试来源。粘贴 OAS3 YAML（缺失分页声明）可补配并实际读取，覆盖状态正确；×、Esc、遮罩关闭及重开正常。390×844 检查无横向溢出，内容内部滚动，关闭与保存按钮始终可见。

收尾：`npm run check` 通过类型检查与全部 137 项 Node 测试；`npm run export:html` 离线单文件构建通过；`git diff --check` 通过。
