# 企业冷启动向导（FEATURE_024）

2026-09-22；本地单企业范围，未发布。设计与票见 [FEATURE_024](../features/v0.1.0.md#feature-024)。

## 使用与实际范围

空空间自动显示五步初始化；已有企业从“完善初始化”进入。仅显示居中的五步内容及步骤操作，初始化期间隐藏全局页头、额外说明栏与助手；完成后返回原企业概览，恢复完整界面。进度随操作保存，关闭、刷新及服务重启可恢复。

1. 连接模型：复用服务、模型 ID、自定义地址及协议设置。API Key 单独保存在运行目录的 `credentials/models.json`（目录 0700、文件 0600），不进入企业档案、对话、浏览器草稿或设置回执。留空复用，主动删除后重启仍保持删除。产品不主动让保存的密钥过期，服务商撤销、到期或余额限制仍以真实请求为准。
2. 认识企业：名称与行业必填，可补充地区、官网、业务及目标。明确点击搜索后，调用现有 KodaX 企业研究链，要求核对同名主体、提供出处并保留未知。搜索可跳过。
3. 选择行业本体：20 个起步包中 14 个优先覆盖金融细分，可勾选概念、修改名称及定义、预览对应关系。模板采用通过共同基础本体服务，保存用户选择依据，建立未映射定义，不生成虚构客户、交易或其他实例。保留已有定义，待核对候选需先处理；操作可幂等重试。
4. 连接资料与系统：按所选行业推荐业务资料、企业知识 MCP、只读 OpenAPI 和飞书文档入口。复用现有真实连接向导及文件上传；登录与已读取内容是不同状态，支持稍后接入。
5. 准备开始：显示真实概念/关系/资料/映射数量和构建缺口，进入原企业与数据页。

金融细分：银行、证券经纪、保险、公募基金、资产管理、私募股权与创投、支付与清算、消费金融、融资租赁、商业保理、信托、财富管理、期货与衍生品、金融科技。另有零售与茶饮、制造、能源、物流、专业服务、通用企业。它们是可编辑建模起点，不是权威行业标准或预装金融数据。

## 实际验证

- `npm run check`：类型检查与 176 项 Node 测试全部通过。新增/扩展管理 HTTP 回归覆盖恢复、金融目录、企业版本冲突、模板裁剪及真实采用、重试不重复写入、权限拒绝、完成返回、重新进入不覆盖资料；覆盖历史字段别名、清空可选字段和同 ID 改名保护。
- 模型回归清除当前环境变量后重启，验证密钥恢复、不同服务隔离、删除后重启不恢复，以及其他服务的保存密钥不受影响。既有自定义双协议、端点隔离、重定向拒绝和错误脱敏测试仍通过。
- `npm run export:html` 与前端 JavaScript 语法检查通过。离线构建约 5.3 MB，保持原演示入口，不携带凭据。
- 隔离临时空间 `127.0.0.1:8791`，真实 KodaX Runtime 请求本地 SSE 测试夹具，完成保存并测试模型、复用配置、填写银行资料、研究状态与响应、勾除交易概念、刷新保留选择、采用得到 6 个概念与 5 条关系、打开已有 MCP 配置、跳过来源、最终核对 0 份资料和 0 个映射并回到企业概览。
- 390px 和 1280px 浏览器布局检查通过；切换步骤滚动归顶，向导中浮动助手不遮挡操作；已检查前端错误日志为空。真实用户空间仅打开初始化入口，未写入测试企业或更改模型凭据。

本轮未使用真实外部模型凭据运行互联网研究，浏览器研究响应明确标记为本地夹具，不是已检索企业事实。未新增金融厂商专用 OAuth 或原生数据库驱动；金融推荐按实际已有 MCP/API 服务接入。第三方登录及读取仍遵循已有连接器能力和账号权限。
