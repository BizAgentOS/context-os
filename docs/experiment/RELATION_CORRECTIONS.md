## 交付

本体工作区新增局部关系治理入口与候选详情。表单与 Agent 经同一领域服务提出、检查和取消候选；管理员在页面确认具体检查版本后采用。内部对象关系读取叠加有效纠正，保存原目标、源读取依据、理由、提交者依据、责任主体、适用条件和版本回执。采用不会写回源或修改全局映射。

## 验证边界与结果

沿公共管理 HTTP、Agent 工具回调、真实 HTTP/MCP 数据源及浏览器验证。最初测试在缺少 corrections 入口时失败，实现后通过；定向回归覆盖未检查不能采用、同键异参拒绝、相同操作重试返回历史版本、过期基线、两个已检查候选竞争采用、停止时迟到工具不得保存、取消不冒充回滚、源变化使纠正失效、列表仅元数据及指定版本读取。

独立评审使用真实源补充验证：数值 ID 的 01/1 别名不能生成两套纠正身份或重复目标；读取别名解析后指向同一有效纠正。分页末页不伪称全量。冲突属性仍为 null 但底层来源值变化也会使指纹失效；来源返回顺序改变不导致误判。授权 v2 消费依然读原始 HF002，不携带内部 correction。慢响应表单冻结输入，失败后恢复原稿；列表和详情丢弃过期响应。最终复核发现并补齐256KB实际序列化字节约束，中文大字段反例先红后绿；不把未执行的预算宣称为保护。

类型检查与113项 Node测试通过；22项 Python测试通过；离线 HTML 导出通过。无独立 lint 脚本。Standards 与 Spec 独立复核最终均为0遗留发现。两项新 Node测试覆盖生命周期与数字身份/分页反例，以及 UTF-8 大字段超过256KB时无候选/回执残留；不依赖评审临时脚本。

## 限制

单企业本地管理员身份，非多用户审批平台。目标集合和原关系均最多20个，保存依据上限256KB；治理列表最近40条，历史正文依引用读取。多源读取非原子，不能锁住上游并发更新。业务真实由用户判断，提交者自由文本不是独立验证证据。源事实漂移需重新调查与提出候选。内部采用不自动发布给外部消费者，外部迁移由 FEATURE_016 验收。其他旧操作未统一获得此服务的幂等保证；全局映射修订是下一票。
