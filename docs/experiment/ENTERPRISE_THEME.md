# 企业与数据页深色视觉修订

2026-09-17 · FEATURE_018 · 本地实验，未发布。

用户指定参照当前本体工作区，只修改视觉、交互反馈和动画，保持具体内容及呈现方式。新主题沿用深青黑空间背景、半透明青绿面板、浅青按钮和暖金色重点；原企业主体、纵向数据统计、上传资料、HTTP API、MCP 和三种接入方式说明维持原结构。

实现位于 `web/agent/app.css` 的企业主题区，限定于企业页及其资料/连接弹窗；不改变数据获取、模型调用、授权或保存逻辑。全局导航与助手只换肤，仍使用原位置和尺寸；模型设置和能力弹窗不随企业主题变化。新增动效为短暂错峰入场、箭头悬停位移和弹窗浮入，`prefers-reduced-motion` 下关闭新增动画与过渡，无持续背景动画。

## 实际验证

- 真实海致科技页面：企业主体、上传、API 和右侧服务列在修改前后的 DOM 边界完全一致；企业卡 456×384、上传/API 各 216×192，位置保持不变。既有内容和数据来源代码未因主题修改。
- 独立临时状态目录及 8793 端口：验证空企业、企业档案、上传资料、三种方式说明、Swagger/OpenAPI 和 MCP 面板可打开与关闭；说明仍只有三类介绍。未登录、授权、上传或执行外部接口请求。
- 390×844：总览保持原单栏顺序；画布 `scrollWidth === clientWidth === 390`。说明弹窗改为原有单栏，内部 `scrollWidth === clientWidth`，可纵向滚动，Esc 关闭。
- 消费与治理页面不匹配企业主题，恢复原背景；本体页继续使用自身主题。
- JS 类型检查、CSS 解析与差异空白检查通过。减少动画分支经源码核对；未修改操作系统动画设置。

临时验证环境与真实空间隔离，完成后停止。不将测试样本、账号或连接写入真实企业；本轮未验证真实外部服务读写或 AI 推理。
