# ADR-008：唯一新接入合同为发布 + 接入方 + v4 / MCP

- 状态：Accepted（设计决定，非实现完成）
- 日期：2026-10-19
- 关系：收敛 ADR-002 的外部适配入口，沿用 ADR-004 的发布锁定与当前授权检查；不撤销存量读取合同。

## 背景

v1/v2/v3 消费、旧数据集、发布接入同时可新建，使用户难以判断哪个版本、哪些数据和权限真正生效，也让 Agent 继续推荐旧路径。

## 决定

1. 唯一新建和维护路径为发布 + 接入方，外部使用 v4 HTTP / stdio MCP。发布固定工作版，接入方固定发布与明确的实体、属性、关系和依据许可。
2. v1/v2/v3 消费者和旧数据集工作台进入历史接入，只读查看、可撤销，不新建、不修改，Agent 也不能提议旧管理路径。
3. 冻结后旧读取按原许可兼容；FEATURE_067 再移除旧接口与服务，实际下线时间需用户确认，保留审计导出。不能以“冻结”声称“已移除”。
4. 接入升级展示具体差异与范围内影响，许可不自动扩张，签发新密钥并原子撤销旧密钥；撤销即时生效，在途返回、历史证据与重放均检查。
5. 工具、配置与说明来自实际执行合同；显式实时部分如实标注。可选 Agent 委托默认关闭，并与普通读取使用相同发布和范围。

## 取舍与替代

不继续并行扩展四套新建合同，也不立即破坏存量客户端。接受过渡期的只读兼容成本，减少新授权和版本模型的歧义。

## 后果

冻结须覆盖 HTTP、Agent 工具、UI 和直接服务写边界；新路径可复用底层数据集 / 视图实现，但不能重新开放旧管理入口。旧读取保留到明确下线，不额外授予权限。

## 实施关联

FEATURE_039 冻结旧写入与界面；051、055 扩展共同查询与发布接入；067 最终下线。接口细节在[消费设计](../DATA_CONSUMPTION_DESIGN.md)，状态以[台账](../FEATURE_LIST.md)为准。

## 重议条件

目标客户确有无法迁移的合同依赖时记录明确兼容范围与期限；公网或远程 MCP 需要单独的身份、安全与部署验收，不能由本 ADR 推导已支持。
