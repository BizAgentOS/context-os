# 产品目标

## 产品定位

**Agent DataEngine 是位于数据生产者与消费者之间的企业语义数据引擎，负责接入、加工、组织和持续维护企业数据。**

业务系统、文档与业务 Agent 产生数据；DataEngine 将这些数据组织为企业对象、关系、业务定义、计算函数和来源证据；外部 Agent 使用它们完成具体业务任务。

## 要解决的问题

1. 同一个人、门店、产品或项目，在不同系统里有不同编号和名称。
2. 同一个业务术语可能对应不同口径，Agent 每次临时解释，结果不一致。
3. 原始材料混合了当前事实、旧记录和推测，结论难以核对。
4. 新数据与业务变化出现后，原有映射、定义和查询容易失效。
5. 多个 Agent 重复整理和理解相同材料，改进难以复用。

## 希望形成的能力

- 用稳定身份组织企业对象，连接属性、关系、状态、历史和证据。
- 将业务口径变成明确的定义，并由程序执行查询与计算。
- 通过对象接口、MCP 和按任务整理的上下文提供数据。
- 由内部 Agent 调查语义问题并提出修改，经检查后更新本体。
- 让用户查看来源、本体、对象与变更，纠正业务含义。

## 产品边界

DataEngine 建设和维护数据资产。销售、客服、采购等最终业务任务由外部 Agent 或业务应用完成。

KodaX Runtime 和 NOOA 式对象访问用于内部 Agent 的实现。它们帮助加工和维护数据；对外消费应通过稳定的数据接口进行。

## 长期价值

**一次对象、口径或本体改进，可以被多个下游任务与 Agent 复用。**
