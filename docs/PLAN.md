# 开发步骤导航

当前开发档案为 **v0.1.0**。用户已明确首轮 MVP 用于展现 Agent 构建企业大脑的产品思路；按 [PRODUCT.md](PRODUCT.md) 和 [MVP.md](MVP.md)中的连续体验推进。

## 当前体验顺序

Agent 入口与企业理解初稿 → 接入第一份资料 → 有依据的本体候选与实例 → 简易报告 → 一次记忆更新。企业理解、接入和建模可根据新信息往返补充。

[主 Agent 行为设计草案](AGENT_DESIGN.md)已沉淀到 FEATURE_003。**当前先评审 Agent 本身：职责、下一步判断、工作状态、提问与自主行动、成果及完成条件。** 用草案中的热力连续对话检查行为是否符合产品想法，本阶段不进入实现票、SDK 接入或前端改造。

后续依据行为设计再安排企业理解/首份资料保存与重开，以及本体对象的关系访问、方法组合、报告与更新。本体对象 harness 是首轮 MVP 核心能力；首段体验无需等待完整 MCP 与方法对照。现有浏览型实验室保留为可复用基础。

**功能状态统一查看 [FEATURE_LIST.md](FEATURE_LIST.md)**；每项工作的设计、票依赖和完成勾选统一保存在 [v0.1.0 设计文档](features/v0.1.0.md)。本页不再维护另一份进度清单。
