# 开发步骤导航

当前开发档案为 **v0.1.0**。本轮目标是用最少的操作创建企业记忆，范围以 [PRODUCT.md](PRODUCT.md)、[MVP.md](MVP.md)及用户 2026-09-08 确认的[记忆画布设计](CANVAS_DESIGN.md)为准。

## 当前体验顺序

企业空白画布 → 对话创建企业信息 → 自动进入数据来源 → 接入真实资料 → 进入本体与对象 → 查看并确认定义 → 数据消费方、访问权限与实际调用（第四页规划中）。

前三页已经实现，第四页目标见[数据消费与访问治理](DATA_CONSUMPTION_DESIGN.md)。各页保留一个有界对话上下文。对话逐渐退出画面，企业记忆独立保存。当前只展示形成的企业内容与必要交互，不设置任务、历史会话、报告和更新页面。

KodaX SDK 与 NOOA 式对象工作区复用已有实现，后台执行能力见[技术设计](AGENT_BLUEPRINT.md)。T003-04 页面上下文与推进、T005-04 记忆画布已经完成，验证入口见[画布运行说明](experiment/CANVAS.md)。此前报告与更新链路保留为[历史验收](experiment/AGENT.md)，不扩大当前界面范围。

**功能状态统一查看 [FEATURE_LIST.md](FEATURE_LIST.md)**；每项工作的设计、票依赖和完成勾选统一保存在 [v0.1.0 设计文档](features/v0.1.0.md)。本页不再维护另一份进度清单。
