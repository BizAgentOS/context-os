按 [CodingSkills 开发流程](DEVELOPMENT.md)逐项推进：登记 Feature → 补齐设计 → 细化当前任务 → 实现与验证 → 更新状态及本地提交 → 维护变更日志。用户可以直接指定 Feature ID 或票号。
