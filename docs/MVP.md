# MVP：v0.3.0 核心产品闭环

更新：2026-10-19。本轮最小范围按阶段 0—2 组织，完整版本仍含数据接入和试点准入，见[v0.3.0 设计](features/v0.3.0.md)。本文件规定交付目标，Feature 状态只在[台账](FEATURE_LIST.md)，文档同步不会自动完成功能或发布版本。

## 最小完整体验

接入数据 → 程序生成初稿 → 问答验证 → 缺口交接构建 → 提议、复验、预览、人采用 → 发布 → 两个独立接入方消费。

一个企业空间、一个 Agent、构建 / 问答两种模式，数据 / 本体 / 发布与接入三页，共同工作版、待处理与长期会话。第一阶段单管理员，星桥主样本加独立留出样本，评测答案不进入模型输入。

## 用户可完成的任务

1. 接入真实结构化来源，看到来源状态、规模和数据截至，由程序生成实体与关系初稿。
2. 看懂对象和逐属性依据、未知与冲突，确认中文命名；通过同一待处理队列决定结构变化。
3. 提业务问题，得到真实版本、数据截至和覆盖；无法回答时知道是缺类型、未绑定、未匹配或身份缺口。
4. 将缺口交给构建模式修复，查看复验和原问题重放前后，经采用回到问答确认。
5. 发布固定工作版，创建两个不同范围接入方，验证升级、撤销与历史读取。

## 验证与限制

公共边界为管理 HTTP / 运行工具、真实临时来源、浏览器和独立消费 HTTP / MCP。模拟 driver 验证合同与拒绝，真实 KodaX 验证实际方法加载、工具执行与保存，二者分别记录；只说明真实跑过的范围。

最终同时记录首个正确答案时间、固定问题准确率、人工决定量、可解释率与模型成本。覆盖版本冲突、同键重试、停止后迟到、权限撤销、源失败、零 / 多匹配、分页、桌面 / 390px / 键盘。隔离测试空间，不修改用户来源或凭据；未通过的退出标准保留未完成。

第一阶段不做继承与命名空间、OWL 推理、图数据库、任意 SQL 对外开放、源系统写回或自动业务动作、多租户、SSO、行级权限、公网部署及计费。结构化数据按 ADR-004 保存不可变快照，不能沿用“原始数据不默认复制”的旧假设。

### 最小完整体验

企业与数据 → 基础本体 → 分类来源接入 → 本体工作区查看融合并修订 → 消费与治理 → 独立 Agent 查询。

基础本体可先形成有依据但未映射的概念。没有可执行映射时不伪造业务实例；采用基础定义也不自动开放消费。各页始终可查看，首次引导不强制穷尽公司信息或接完全部数据源。

### 用户应能完成的任务

1. 仅提供企业名称和业务，获得可修改、有依据的小型基础本体；上传或公开研究补充同一份内容。
2. 在第一页连接真实能力，看到可读样本、用途、映射与限制；失败明确，凭据不入聊天。
3. 在第二页看到一个业务对象的多源属性，追查某个值和关系的依据，理解未匹配和冲突。
4. 通过直接操作或 Agent 完成同一项修订，查看前后差异、检查范围和实际采用结果。
5. 在第三页启用许可范围，复制可用接入说明；独立 Agent 不开浏览器即可发现、查询和取证。
6. 处理一次语义变更的消费者迁移；不同范围的读取、撤销、源变化与版本冲突表现准确。

### 验证边界

沿既有管理 HTTP/领域工具、独立 HTTP/MCP 来源、浏览器及外部客户端验证。虚构热力案例同时包含投诉、附源服务记录、回访、业务文档和 BI 指标。真实跨源结果作为依据，不在模型输入中预置评测答案。

实现票各自验证新增行为；最终整链使用真实 KodaX、桌面/窄屏/键盘和两个独立消费者。覆盖同名公司、资料冲突、分页/粒度、零/多匹配、局部失败、旧版本、重复提交、同键不同请求、取消与撤销竞态、重启、存量迁移和离线导出。

任务成功需有实际保存或执行回执；调查以证据不足结束也可有效完成，但不能宣称业务事实已经成立。模拟测试与真实模型/来源验收分别记录，未完成项如实披露。

### 暂不纳入

任意文件格式、所有厂商专用连接器、全量模糊实体消歧、通用 SQL/OWL 推理、任意 CodeAct、源系统写回、全企业后台巡检、多租户/SSO/记录级权限、公网部署及计费。原始数据不默认整体复制；必要证据保留另有范围与权限。
