# 企业自主知识构建：首批实现与操作边界

更新：2026-11-05。对应 FEATURE_069、P0/M1/H1 首批纵向切片；不是整份自主平台路线图完成，也不改变 0.3.1 发布号。

## 当前可执行路径

管理员保存 MySQL 连接及授权表范围 → 后台 observe 固定表目录并完整读取 → table 来源暂存 → reuse 检查已批准映射（兼容时跳过模型生成）→ 不兼容时逐表 discover、统一协调 → 在同内容草稿上逐表 plan → 本地 collect 预检 → 集中决定包 → 按权限保存决定、发布、批准和构建。首轮本体和身份事项同屏处理，不要求先发布后再分析身份。定义被编辑后旧计划整体失效，需要重新生成，不能沿用旧批哈希。

来源连接和决定包在工作台最上方；CSV/PDF 上传保留为补充入口。手动选中来源和草稿后生成计划也进入集中决定路径。仅采集不调用模型；“采集并分析变化”会使用运行时配置的模型。该选择是明确调用授权；没有配置模型时不会隐式换模型。

父 discover 与下一 plan 任务同事务保存；plan、preparing 决定包和本地 collect 任务同事务保存。collect 无模型依赖，重启后可继续；失败显式重试，不重跑已保存的发现/计划。人工等待不占 worker 或数据库事务。collect 对已发布、预检已自动批准且无阻断的计划直接执行构建；新本体首次发布仍要求 admin。

## 安装、迁移与数据安全

1. `npm ci` 安装锁定依赖，MySQL 原生驱动为 mysql2 3.24.6。
2. 操作者核对 `.env` 的平台 PostgreSQL 地址后，显式运行 `npm run knowledge:init`，增量应用缺失迁移至 007-structured-compiler.sql；不要 reset。启动要求已有 007；001–006 不能直接运行本版服务。
3. 启动 `npm start`，沿用现有本机认证。管理员在“企业数据源接入”填写 MySQL 配置。凭据只进 CredentialVault 加密区，不出现在状态、目录和观测返回中；备份时需按现有密钥保管规则保留 vault 与密钥。
4. 实际接入应使用只读账户，限定数据库及表 SELECT/元数据可见权限；程序使用固定元数据 SQL 和只读事务，不接受模型 SQL。当前管理员可限定表，尚无列级授权界面。
5. 远程连接要求 TLS 验证；本机可显式关闭。自签 CA 可通过 API 的 config.ca 提供，页面目前没有 CA 输入。不得为了连接成功关闭远程证书验证。

11月4日曾初始化独立测试库；11月5日本轮没有运行测试、初始化任何数据库、读取企业 MySQL、修改模型配置或调用真实模型。升级提示版本后旧队列任务显式报不兼容，需操作员排空或按原产物/当前配置处理，不自动付费重跑。

## 来源、覆盖与激活契约

- 首版验证 MySQL 8.4 / InnoDB；驱动仅接受 MySQL 8 系列，MariaDB、其他引擎不假定兼容。目录只代表账户可见对象，不推断不可见表不存在。
- 稳定资产是连接＋库＋表，记录键是复合主键原值序列；业务对象身份单独治理。关键排序和比较使用原始带表别名的主键列，避免 CAST 字符串投影改变数字分页顺序。
- 每张表单连接 REPEATABLE READ 一致读，固定目录前后比较；跨表没有企业级同一时点保证。读取中断、超限或 DDL 漂移均不形成完整批次，需新 operationId 重开；不能从旧游标恢复原一致读视图。
- 分页先持久化，成功后生成不可变 source_records 和版本清单；source_versions.content 不嵌入整表，也不经 CSV/Parquet。批次失败清理临时分页，保留失败回执。较新完整批次已完成时，旧批次不能回退 observed_version。
- DECIMAL、大整数及日期保留字符串；SQL NULL 另有原值表示，证据可区别实际空字符串。NULL 属性不猜值；必填 NULL 阻断。零值日期不猜业务有效期。无时区 datetime 的业务含义仍需映射确认。
- 采集只推进 observed_version，active_version 与旧 accepted 声明继续服务。成功构建按来源事务替代旧贡献并激活；其他来源与人工修正保留。等待时页面披露“观测/暂存”与正式版本；旧证据继续从原不可变记录解析。
- 当前仍是整表完整读取、按来源替代；没有 CDC、记录级差分替代和删除对账。缺行、无键及不完整扫描不会被当成删除授权。空输出不替代旧来源，其旧事实仍参与其他来源冲突预检。

## 集中决定和恢复

面板列本体、身份组、事件和系统错误，身份 same 不预选、各组独立，可批量选择并设置单组例外。决定绑定包修订、候选哈希、计划修订和事件哈希；系统错误不能用同意绕过。定义编辑使整计划失效，身份决定后新出现的事实冲突可能需要再一轮决定，不承诺任意修改永远一轮。

发布仅 admin；editor 可预检和批准已发布本体上的计划。发布、批准、构建分别写回执；构建失败后再次提交复用已发布本体及已批准计划，不重复发布或调用模型。接口中断停留 submitting 五分钟后允许显式恢复；不得并行重复提交。

相同来源资产范围的新决定包取代旧未完成包并保存 superseded_by；同计划重复创建返回原包，不反向取代新批。归档须操作者、理由及修订，保留候选、指纹、取代关联和原证据；归档/取代不等于批准，不能继续提交。等待超过30天提示复核，不自动过期删除或批准。提醒目前只在打开面板时显示，尚无主动通知调度。

新本体已发布但构建未完成时，若新类型/属性/约束/关系与对象现有声明不兼容，对象查询显式返回未就绪；历史 knownAt 可按旧发布解释。当前保护偏保守，未实现通用语义迁移和按业务范围选择适用发布，本体演进完整能力仍归 B1。

## 限额与未交付项

当前每次最多50个来源资产；单表采集默认10000行、API最多100000行，最多200列及100MB编码记录，单读120秒，单查询30秒，页500行。二进制/空间等不支持类型显式拒绝。发现/计划只给模型10行样本和目录；输入预算仍100/180KB，知识构建仍每来源2000条声明。采集上限不代表知识构建容量，超额显式失败，不能宣称已验收10万行持续维护。

后续工作：受管文档目录；业务目标/通用与合同领域配置；定时同步、调用配额和预算预留；更广范围的映射复用；记录级替代与删除/漂移对账；自动发布服务策略；身份/部署授权；冻结金标准、真实效果和容量验收。本版仍是本机单企业、实例成员共享可读资料，不是已验收企业生产部署。

当前同范围、同结构、同已发布本体且已有兼容构建头的普通数据变化可复用已批准映射；其他变化进入 discover/plan。旧 v10 计划没有编译策略标识，不自动提升为兼容模板。不得把机制实现解释为领域质量或真实模型效果达标。

## 原生日期与来源名称修复

数据库列名含time不决定其日期类型。实际日志time为decimal耗时，原错误来自create_time的有效起点解析；迁移表先在start_time解析失败。报错现明确标出表、绑定、取值列及from/to实际来源字段，不再展示大段Zod正则。

MySQL TIMESTAMP由本适配器固定UTC会话读取，空格日期可按UTC解析；DATETIME不包含时区，须用户在计划顶部显式填写datetimeOffset（如已确认的+08:00），不使用机器所在地猜测。该设置仅适用于本计划中同一固定时区的无时区日期时间，跨时区或夏令时来源不得用单一偏移冒充完整规则。保存后重新预检，无需付费重抽。CSV/固定时间仍要求明确时区。日期格式与起止区间是独立校验，原正区间规则保持，不自动改绑定。

计划编辑器按真实来源显示“数据库表/CSV文件”和表名；内部csv仍是兼容保留的结构化映射分组名，不代表把MySQL导出为CSV。此补丁只静态检查，回归夹具待显式执行，原66/680通过数不外推至本补丁。

### 枚举候选修复与恢复

“缺少完整数据库ENUM声明”不再令整次候选生成失败。数据库声明只是闭合取值的一种依据；整数/字符串列上的业务枚举保留为草稿候选，程序添加“确认业务枚举完整性”集中事项，列出当前拟采用取值，发布前需据业务字典/规则/说明确认，或编辑草稿取消封闭约束。样本不能证明取值完备，未确认不会自动采用为正式约束。类型/证据校验仍保留。

此补丁不升级v11提示、不修改模型输入指令或007结构。重启服务后，原失败任务可按原配置显式重试，已完成表分析复用；失败阶段可能再次调用模型，本轮未代为重试。不必重新采集或清库。若配置或来源确实已经变化，仍按既有不兼容提示处理。本轮新增回归未运行，静态审查不等同于真实业务验收。


### 日期候选修复与恢复

缺少物理日期列依据只说明宿主尚未验证日期表示，不能据此判断该字段是耗时或断言实际值不符合datetime。字符串日期、数值时间戳均可能表达日期；程序不凭名称判定，也不猜数值单位或时区。候选生成保留草稿datetime及原始证据，继续其他表分析，最终集中展示“确认日期表示与业务含义”（包括证据列/类型），由操作者确认或先修改草稿类型。

该确认不提供新转换器：当前构建仍校验具体列的日期值、时区及有效区间，未知单位数值/耗时仍不接受，epoch转换尚未实现。先按来源实际表示调整类型/映射/时区，不能通过确认绕过格式校验。v11/007不变，无新迁移；重启并刷新后可原配置重试当前失败任务，失败步骤可能付费重调、成功步骤复用；无需重新采集、清库或重建全部任务。本轮没有代为重试或运行测试/数据库/模型。
