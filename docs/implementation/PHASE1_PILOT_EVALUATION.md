# 第一阶段试点评测与运行基线

日期：2026-11-02。本文提供可执行的标注、冻结和记录约定，不虚构尚未选择的企业场景、业务阈值和行业准确率。合成机制测试与真实业务效果分开验收。

## 开始条件

指定一位业务负责人及一位争议裁决人，确定业务问题、授权资料范围、本体发布版本、模型/提示版本、权限需求、错误代价及指标门槛。存在部门/字段隔离需求时，当前实例不能接入该批资料。

先抽样摸底，统计不同关系/事件的阳性样本和罕见类别；按资料来源、格式、难度和业务类别分层。样本量根据各层的独立判断数和可接受误差确定，不能只数文档。冻结后新增案例形成新版本；调参集与验收集分开。未冻结阈值时结果只能是探索性报告。

## 标注记录

每份资料须由标注者阅读全文或明确记录覆盖范围，列出应有声明，以便评估漏抽。高风险/歧义案例由两人独立标注并裁决；记录一致率和争议类别，不让模型输出充当唯一真值。

每条记录至少填写：

```json
{
  "caseId": "待分配",
  "sourceVersionId": "待绑定不可变资料版本",
  "split": "acceptance",
  "category": "否定/计划/条件/口径/身份/时间/普通事实",
  "expected": {
    "subject": "业务对象或来源内提及",
    "predicate": "已发布本体成员",
    "valueOrObject": "标注值或关系端点",
    "semantics": {"polarity": "affirmed", "modality": "actual"},
    "comparison": {"unit": "yuan", "currency": "CNY", "scope": "tax-included"},
    "validity": {"from": null, "to": null, "precision": "unknown"},
    "evidence": "不可变版本内字段或逐字引文位置",
    "expectedDisposition": "accepted/pending/incomparable"
  },
  "annotators": [],
  "adjudication": "未裁决",
  "notes": "不适用字段按标注规范省略，不能用占位数据运行验收"
}
```

标注答案、争议裁决和测试生成器内部数据不能作为被测模型输入。保留模型原始输出和主机校验结果，定位修正与首次失败分别记录。

## 逐环节报告

| 环节 | 必报结果 |
|---|---|
| 本体候选 | 概念覆盖、重复、端点错误、业务可用性；不强求唯一命名 |
| 抽取 | 实体/属性/关系分别报 precision、recall、F1；漏抽必须对照阅读全文标注 |
| 语义 | 否定、计划、假设、条件的识别和误采纳数；不能仅检查 JSON 合法 |
| 身份 | 误合并、漏对齐、错误标识、人工纠错成功/失败及耗时 |
| 时间 | 起止、左闭右开、未知、迟到资料及历史查询正确性 |
| 证据 | 逐字定位成功率与语义支持率分开，能定位不等于结论为真 |
| 融合反馈 | 同口径冲突、不可比识别、修正依据、再次同步及旧历史 |
| 最终业务任务 | 当前版本未提供完整问答，不报告问答准确率 |

对业务否定、条件误采纳等高风险错误单独列例，不能被平均综合分掩盖。必须同时报告未支持、拒绝和待处理数量，不能靠丢弃困难案例提高准确率。

## 成本、负载及权限记录

每轮记录初次构建、增量、变更回补、失败恢复四类场景。通过 `/api/list/jobs` 取最近尝试的耗时、输入字节、模型调用、提供方可用数值 usage；通过 `/api/jobs/{id}/attempts` 查看逐次尝试，不能只算最终成功的一次。中断尝试的缺失 usage 保持未知。`cost=null` 表示未核定费用，不是免费；输入字节不是 token。保留供应商账单/价格版本与人工复核工时，在报告中另行核算。解析/OCR、存储、缓存、运维及失败重试也应计入；首期没有 OCR，不能宣称已测。

| runId | 资料/本体/模型/提示/策略版本 | 场景 | 文档/记录/声明量 | 耗时与 token | 人工分钟 | 核定费用 | 失败/重试 | 未知项 |
|---|---|---|---|---|---|---|---|---|
| 待填写 | 待填写 | 初建/增量/回补/恢复 | 待填写 | 待测 | 待测 | 未核定 | 待测 | 列出缺失 |

冻结代表性查询：对象详情、关系展开、证据读取、双时间历史、反馈重算。记录度数/扇出、结果规模、并发、p50/p95 延迟、数据库与内存资源。以首批真实资料规模作为基线，未测前不承诺通用容量或生产 SLA。

本实例授权用户能读所有来源及声明。试点负责人须在资料接入前确认这一授权范围；需要隔离则先实现并验证精细权限，不能仅隐藏引用。
