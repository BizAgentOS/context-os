## 运行中发现并修复

1. **类型错误**：列表分支中不可达的类型比较、测试中的可能缺失对象及证据返回类型不完整；已修复，类型检查通过。
2. **Node 启动失败**：构造函数参数属性不被直接运行的 TypeScript strip-only 模式支持；改为显式字段赋值，并通过 erasableSyntaxOnly 阻止再次引入。
3. **权限响应不一致**：领域权限拒绝曾统一返回 400；增加 AccessDenied，统一以 403 返回，HTTP 测试覆盖。
4. **分页禁用丢失**：界面异步操作结束后把所有按钮启用；改为恢复操作前状态。浏览器中复查后空列表的下一页保持禁用。
5. **GLM 工具请求被拒绝**：基础请求可用，携带复杂领域 JSON Schema 的工具请求返回 400 / 1210。知识适配器改用简单的 JSON 字符串传输封装，领域 schema 在主机严格校验；未删除类型、证据或时间校验。参考：[智谱工具调用文档](https://docs.bigmodel.cn/cn/guide/capabilities/function-calling)。
6. **模型引用偏移不准确**：真实 GLM 本体结果的部分原文逐字正确，但字符位置偏移 3 个字符。主机现可将唯一逐字引文重新定位，并保存原始位置提示；不存在或无法消歧的错误引用仍拒绝。使用同一份真实模型输出复验，不增加付费生成。
7. **验证脚本页码假设**：多页 PDF 夹具曾错误要求每条证据都在第 1 页；改为检查对应原文实际所在页，另有精确页码测试和单页生成样本验证。

## 真实模型结果如何理解

本体生成和声明抽取是独立评测：先调用模型提出候选本体，另使用冻结的人工本体测试抽取，避免将生成本体质量与抽取质量混在一起。

6 条抽取声明为合同编号、合同客户、合同金额、E001 在 4 月至 5 月的负责人关系、E002 自 5 月起的负责人关系、企业名称。金额采用精确十进制字符串；原文未指定时间的声明保持 unknown。模型生成不是事实真伪保证，当前仅对合成输入作人工检查与程序校验。

首次复杂工具请求失败、首次本体定位校验失败均保留在本地工作记录中，不覆盖为首次成功。修复后，本体采用原始模型输出重放并通过完整任务校验；抽取在真实模型调用中完成，所有原文引用均可定位到实际 PDF 页。原始失败样本已固化为 `tests/knowledge/fixtures/glm53-output.json`，不会被真实评测脚本作为模型输入。

SDK 未提供完整费用信息，不报告准确费用或将合成小样本结果外推为行业准确率。正式两项模型生成约 4 分 49 秒，此外有少量参数诊断请求。

## 环境与安全边界

本机无运行中的 PostgreSQL、Docker 未启动。本轮从 npm 获取临时 PostgreSQL 17 二进制，在本次工作目录建立专用实例，仅监听 127.0.0.1:55439。由于 macOS 沙箱禁止其共享内存操作，初始化和启动单独使用获批的执行权限；没有安装全局数据库服务。

测试数据库互相独立：机制/HTTP、真实模型、浏览器、CLI 分别使用专用数据库。自动集成测试拒绝已有 knowledge schema 的数据库。使用原模型的读取配置和所需凭据仅限内存，不输出密钥，不变更原模型配置。

浏览器验证未自动操作操作系统的原生文件选择窗口；上传路径由 HTTP 集成及真实 PDF API 验证覆盖。未做完整键盘与可访问性验收，也未单独设置桌面/移动断点；截图只证明本次观察到的视口。
