# ADE 总体架构（HLD）

更新：2026-10-19。本文负责模块、数据流与责任，产品价值见[PRD](PRODUCT.md)，模式见[Agent 设计](AGENT_DESIGN.md)，领域字段与不变量见[语义契约](SEMANTIC_CONTRACTS.md)。目标按[v0.3.0 Feature](features/v0.3.0.md)逐项交付，架构采纳不表示实现完成。

## 系统与职责

人类三页 Web / 内部 Agent / 外部 v4 HTTP 与 MCP → 共同语义、变更与授权服务 → 显式本体、绑定、身份、查询、证据 → 来源连接与快照执行器。KodaX 保持唯一内部模型工具循环；普通外部消费不经过模型。

| 层 | 责任 | 边界 |
|---|---|---|
| KodaX | 模型调用、工具循环、SDK 事件与取消 | 不决定业务事实和许可 |
| 宿主 | 身份、模式、上下文、工具装配、执行池、预算与生命周期 | 不以 Prompt 替代领域校验 |
| Skill | 观察、提议、复验与解释的方法 | 不生成工具、权限或额外模型循环 |
| 领域服务 | 语义、绑定、身份决定、变更、复验、采用、查询、证据与版本 | 不保存布局为业务事实 |
| 来源适配与执行器 | 获准读取、分页、快照、画像、SQL 编译执行、资源限制 | 不自行确认业务含义 |
| Web | 可视化、共享引用、差异、决定与回执 | 不自建计数、身份或权限 |
| 消费适配 | 发布与接入方范围的 HTTP / MCP、动态合同 | 不转交来源凭据或启动模型才能查询 |

程序发现、人和 Agent 修正结构，经复验后人采用；Helix 是提议者之一。语义、绑定、数据、查询四层独立，规则发现不等于完整本体模型。稳定对象引用与共同服务贯彻每个入口，见 ADR-001—008。

## 数据接入与快照

结构化来源默认同步为本地不可变快照（DuckDB 读入、Parquet 保存），工作区默认查已采用快照，发布固定快照集；显式实时路径标注读取方式。文件 / API / 数据库不因来源种类默认改变该规则，见[ADR-004](ADR/ADR-004-managed-snapshots-and-pinned-releases.md)。

连接器按 Excel 多 sheet 与 CSV 编码识别 → MySQL / PostgreSQL 只读表 → 分页 API、OAuth2 刷新与嵌套展开 → 飞书多维表格 → PDF / DOCX 推进（FEATURE_057—059、062）。分页支持页码、偏移、游标、Link；失败最多重试 3 次，响应 20MB、60 秒是目标上限，不冒充现有连接器已支持。

每来源周期为手动 / 每小时 / 每天 / 每周，新来源默认每天；可靠更新时间字段可增量，否则全量。不同来源最多 3 个并行，同源串行；分页中断从成功页续传，重试失败后保留已生效数据（FEATURE_060）。每个来源与回答显示数据截至。

质量熔断不让新快照静默生效：上一版非零而返回零、行数减少超过 50%、身份键重复或空值、关键字段空值率升高超过 30 个百分点、字段结构变化 → 数据问题待处理；旧快照继续服务。阈值可按来源调整，确认新快照或保留旧快照形成有回执的决定。

## 变更、查询与资源

所有结构提议进入同一变更与复验服务，自动采用仅限首次安全构建、同结构重绑及明确的非结构普通编辑；后续新合并、新关系与降级必须由人决定。变更、待裁决、命名、缺口和数据问题从一个投影汇总。发布固定工作版，治理决定进入发布而非仅内部生效。

同一查询层以语义 ID 编译快照 SQL，供构建、问答与外部使用，差别为视图、范围与版本。所有查询包括固定快照经过统一执行器的并发、排队、超时、取消；补充来源批量匹配，不逐对象放大读取（FEATURE_051）。查询回执保留数据截至、版本、覆盖、截断和失败。

交互池按会话各 1 并发，后台池总并发 1；后台文档、重绑和外部委托不占交互槽，同对象写入依版本冲突重验（FEATURE_047）。批量命名后续由 FEATURE_045 接入后台池。来源同步并发与 Agent 池为不同资源约束。停止先使运行写入失效再取消，已提交成果保留。

## 平台与持久化

领域定义、事实快照、治理决定、任务、完整会话历史与 UI 状态分离。大原文 / 快照外置、成果按类别索引；发现值重合先物化分页，高基数先签名复核（FEATURE_066）。

SSE 按对象局部推送，前端拆 Agent 面板、待处理、任务和三页模块，不用模拟点击通信；页面只在前端保存、取消页面完成后自动跳页（FEATURE_049）。演示 / 分享使用正式渲染路径（FEATURE_067）。

凭据统一加密、配置导出不含凭据；被发布引用快照永久保留，其余来源最近 5 版，上传原文默认 90 天。备份为 SQLite 在线备份 + 快照 + 配置，恢复到新目录（FEATURE_063）。成本与三种本地角色属于 FEATURE_064；不宣称已有 SSO、记录级权限或公网部署。

## 当前实现接点与差距

| 接点 | 当前接入（含未发布改动） | 后续目标 |
|---|---|---|
| `src/agent/runtime.ts`、`app.ts` | Node HTTP / Web，KodaX embedded/inline；按页工具，跨页会话、有界上下文、按会话交互及后台各自的 runtime / 停止句柄 | 双模式、结构化执行卡与成本 |
| `src/data/snapshots.ts`、执行器 | 本地不可变快照、字段画像、版本与保留，发布锁定；实时为显式策略 | 统一工作区快照读取、定时增量与质量熔断 |
| `src/engine/program-builds.ts`、`changes.ts` | 确定性独立实体初稿、逐项结构变更、复验与部分采用；关系 / 身份 / 弃用 / 活动分类明确决定，拒绝记忆保留 | 统一待处理中心 |
| `src/agent/foundation.ts`、`src/live/` | 显式语义 / 绑定层、稳定 ID、复合身份、中间表、有限转换、融合取证与纠正；旧采用入口接入统一事务；same_as / belongs_to 和记录决定参与查询，兼容治理决定随换绑保留 | 共同扩展查询 |
| `src/engine/releases.ts`、`workspace-versions.ts` | 工作版固定组合、历史恢复及不可变发布；采用的局部纠正与身份决定固定进入发布和差异，旧发布缺身份字段用空集；待采用项只提示，历史读取及当前撤销生效 | 旧读取接口退出 |
| `src/agent/memory.ts`、`web/agent/` | SQLite 成果、长期会话与分页历史，三页按 SSE 事件和分域快照更新，模块与表单状态独立 | 证据索引 / 外置、统一待处理和面板重构 |

能力台账只登记实际 SDK 接入；inline 不等于沙箱。Helix 的确定性方法沿 `third_party/helix-foundry/` 保留 Apache-2.0 来源，不引入 Helix 模型循环、HelixDB 或整套权限。NOOA 提供有界对象方法参考，不引入 Python Runtime、任意代码执行或全量 SDK 生成。

验证沿管理 HTTP / 运行工具 → 独立真实来源 → 保存与查看 → 外部 HTTP / MCP 的公共边界。模拟、真实 KodaX、真实来源、浏览器和规模证据分开，历史见[运行索引](experiment/README.md)。
